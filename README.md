
# Undertrial Prison Population Forecasting using ARIMA

## Project Overview
This project focuses on analyzing and forecasting the annual population of undertrial prisoners in India using Time Series Analysis. It aims to understand historical trends and estimate future undertrial prison populations using the ARIMA model.

## Objectives
- Analyze historical trends in India's undertrial prison population.
- Perform time series visualization and exploratory analysis.
- Apply ARIMA for forecasting future population trends.
- Understand patterns and changes in undertrial prison populations over time.

## Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Statsmodels
- Jupyter Notebook

## Methodology
1. Data collection and preprocessing.
2. Exploratory Data Analysis (EDA).
3. Time series visualization and analysis.
4. ARIMA model development.
5. Forecasting and interpretation of results.

## Repository Contents
- **Data set:** Historical undertrial prison population data.
- **Programs:** Python notebook containing the analysis and forecasting.
- **Report:** Detailed project report.

## Key Learning Outcomes
- Practical application of time series analysis.
- Understanding and implementation of ARIMA models.
- Statistical interpretation of historical trends and forecasts.
